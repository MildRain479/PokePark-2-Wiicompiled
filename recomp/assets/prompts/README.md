Button prompt icons, drawn over the game's Wii Remote button glyphs in its
text to show what the player has bound to each button (hle_prompts.c).
Named by what they show: `key_<key>`, `mouse_<button>`, `pad_<button>`
(an Xbox controller's). A missing one leaves the game's own glyph; any
100x100 PNG with transparency can be added or swapped in.

Icons by [Icons8](https://icons8.com).
